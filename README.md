# Application Studio

Static personal admissions tracker for Germany and Italy. Serve the repository root with any static web server. University seed records live in `data/`; UI logic in `js/app.js`; styling in `assets/css/style.css`. Existing browser storage key is retained. Export a backup before updates. No cloud sync. Italy entries are research leads, not freshly verified admissions decisions. Keep this repository private if desired; do not commit personal documents or credentials.
